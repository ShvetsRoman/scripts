# Чиста установка RouterOS 7

**Увага:** команда з `--reset` стирає чинну конфігурацію RouterOS. Зробіть незалежну резервну копію; `skip-backup=yes` скасовує автоматичне резервне копіювання під час RESET. Використовуйте фізичну консоль або резервний шлях доступу, особливо під час першого тесту.

## Підготовка

Заповніть приватний `routers/<профіль>/.secrets` (порожні шаблони в архіві), встановіть для нього права `chmod 600`. Ніколи не копіюйте заповнений файл у Git або звіт. Звірте `connection.toml`, WAN/LAN, фізичні порти, пакет Wireless та паролі.

```bash
./scripts/check.sh
cargo run -- plan hap-ac
cargo run -- build hap-ac
```

`plan` не змінює роутер і не виводить секретів. `build` формує приватний `routers/<профіль>/build/setup.rsc`, **який може містити паролі**. Не публікуйте його. Перед реальним застосуванням перевірте сценарій у контрольованому середовищі без розкриття секретів.

## Передавання

```bash
# Копіювання RSC через SCP з перезаписом однойменного файла; без RESET
cargo run -- upload hap-ac

# РУЙНІВНА ОПЕРАЦІЯ: лише для нової установки
cargo run -- upload hap-ac --reset
```

Після завантаження другий варіант надсилає `/system reset-configuration no-defaults=yes skip-backup=yes run-after-reset=setup.rsc` (з урахуванням фактичної назви RSC). SSH може обірватися через перезавантаження. Надіслана команда ще **не є підтвердженням** успішного виконання всього скрипта; перевіряйте результати, журнали й мережеву доступність вручну. Автоімпорт при передачі не використовується.

`apply` залишається заблокованим. Цей менеджер не призначений для повторного накладання сценарію на робочий RouterOS.
