## Межі підтвердження

Наведені перевірки ZIP/структури/синтаксису не замінюють локальний Cargo.
Повторити `./scripts/check.sh` для Stage 5; не оголошувати Stable до PASS.
`Cargo.lock` у базовому ZIP містить лише кореневий пакет, тому Cargo може
оновлювати його під час локального запуску. Цей RC не підміняє lock-файл
неперевіреними вручну записами залежностей.

## Фінальна примітка

Користувач підтвердив 5/5 PASS для Stage 5 Verified Source Refresh RC.
Оновлення Stable торкається лише документації та релізного тесту.
`Cargo.lock` у базовому архіві залишається неповним; перед використанням
`--locked` слід згенерувати і зберегти lock-файл на машині з Cargo.
