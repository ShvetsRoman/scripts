# Тестування, обмеження та безпека

```bash
./scripts/check.sh
```

Перевірка включає `Cargo fmt`, `Cargo fmt check`, `Cargo clippy`, `Cargo test` та документацію TOML; `scripts/check.sh` має залишатися виконуваним (`+x`). Поточні приклади профілів `hap-ac` і `test` містять разом 30 TOML-файлів. Локалізації: `locales/uk.lang`, `locales/en.lang`.

Після кожної зміни джерел, тестів або документації виконуйте `./scripts/check.sh`. **Актуальна** кількість Rust-тестів визначається лише результатами нового запуску; попередні журнали не підтверджують нову збірку.

Контрольні вимоги: PLAN не виконує команд, `apply` заблоковано, секрети не потрапляють у PLAN і Git; захист WAN/Management та порядок Firewall/NAT/WireGuard збережені; кожен профіль працює за TOML без винятків за його назвою. Жорсткого списку номерів фізичних портів немає. Golden RSC не застосовується.

Для перевірки реальної сумісності потрібні RouterOS 7 та налаштований Wireless-пакет. Автоматичні Rust-тести не доводять фактичного успіху інсталяції на обладнанні.
