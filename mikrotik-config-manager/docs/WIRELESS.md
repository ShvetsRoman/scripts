# Wireless: RouterOS 7

Налаштування зберігаються у `wireless.toml`, фізичні ID — у `interfaces.toml`. Профіль визначає `wireless.driver`, а не назва профілю.

| `driver` | Потрібний пакет/інтерфейс | RouterOS меню |
|---|---|---|
| `legacy` | `wireless` | `/interface wireless` |
| `wifi-qcom-ac` | сумісне ARM-обладнання з `wifi-qcom-ac` | `/interface wifi` |
| `none` | радіо не конфігуруються | немає команд |

Починаючи з RouterOS 7.13 тип бездротового пакета є важливим: наявність пристрою `hAP ac` сама по собі **не підтверджує** фактично встановлений пакет. Перед чистою установкою перевірте на роутері:

```routeros
/system package print detail
/system resource print
/interface wireless print detail
/interface wifi print detail
```

Одне з двох останніх меню може бути недоступним — це очікувано. Оберіть у TOML драйвер **відповідно до реального пакета**. Механізму автоматичного визначення немає. Фізичні заводські назви для драйверів можуть відрізнятися; за потреби використовується опційне `default_name` у `[wireless.wlanN]`.

Пароль мережі не зберігайте у TOML; конфіденційні значення належать до `.secrets`. `plan` приховує секрети, а побудований `.rsc` захищайте як файл із паролями.
