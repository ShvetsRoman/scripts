# v0.0.41 Stage 4 — PLAN/BUILD Safety Audit (RC)

- База: Stage 3 Rustfmt Fix RC, підтверджена користувачем 5/5 PASS.
- Виявлений дефект: після успішного створення нового RSC помилки `write_all` / `sync_all` могли залишити частковий вихідний файл.
- Виправлення: `write_complete_rsc()` видаляє тільки щойно створений вихідний файл при помилці запису або синхронізації та повертає початкову типізовану причину. Успішний запис і права 0600 не змінені.
- Регресія: `failed_rsc_write_removes_incomplete_file_and_preserves_io_source` відкриває тестовий файл без права запису й перевіряє його видалення та `Error::source()`.
- Під час помилки валідації секретів та конфігурації RSC і раніше не створювався: рендеринг відбувається до відкриття вихідного файлу.
- Існуючі файли не перезаписуються (`create_new(true)`), і перевірка шляху в `profile_script_path()` залишається чинною.
- SSH/SCP, RESET, CLI, PLAN, TOML, uk/en і порядок команд RouterOS не змінювалися.
- Фінальні Cargo fmt, Clippy, Rust-тести потрібно виконати на робочій машині через `./scripts/check.sh`.
