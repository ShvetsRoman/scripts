# Поканальні виключення

Файл `<каталог>.conf` застосовується лише до каталогу з таким ім'ям у `BACKUP_DIRS`
(`/` в імені замінюється на `__`: `A/sub` → `A__sub.conf`). Додається до глобального `../exclude.conf`.

Синтаксис — `rsync --exclude-from`. Використовується однаково в sync, у dry-run-аналізі й у `verify`.
