description: Запуск тестів та аналіз результатів
agent: build
---

Досліди наявну систему тестування.

1. Визнач доступні тестові команди.
2. Перевір залежності.
3. Запусти відповідні тести.
4. Перевір результати.
5. Визнач відсутні перевірки.
6. Не змінюй код автоматично для приховування помилок.

Сформуй звіт:

- PASS
- FAIL
- SKIP
- TIMEOUT

Для кожної помилки вкажи причину.
Запропонуй наступні кроки.
