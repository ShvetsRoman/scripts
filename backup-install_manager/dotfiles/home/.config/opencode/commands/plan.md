agent: planner
---

Склади план реалізації для поставленого завдання.

Перед плануванням досліди поточний проєкт.

Розроби:

1. Поточну архітектуру та задіяні компоненти.
2. Залежності між компонентами.
3. Мінімальний план змін.
4. Потенційні ризики та способи їх мінімізації.
5. Необхідні тести та перевірки.
6. Критерії завершення.

Не змінюй файли.

Подавай план кроками у порядку виконання.
Для кожного кроку вкажи очікуваний результат.
