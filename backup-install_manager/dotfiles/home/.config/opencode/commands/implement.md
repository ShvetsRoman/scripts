Реалізуй завдання: $ARGUMENTS

Дотримуйся такого процесу.

## 1. Аналіз

- Визнач мову та тип проєкту.
- Досліди наявну структуру.
- Перевір документацію, конфігурацію та тести.
- Не змінюй файли до визначення обсягу робіт.
- Якщо потрібен план, використовуй Planner.

## 2. Вибір розробника

Вибирай спеціалізованого агента відповідно до проєкту:

- Bash — bash-developer.
- Rust — rust-developer.
- MikroTik Manager Bash та RouterOS — bash-developer з додатковим аудитом mikrotik-reviewer.

Не використовуй непотрібних агентів.

## 3. Реалізація

- Дотримуйся погодженого обсягу.
- Зберігай архітектуру.
- Не додавай зайвого функціоналу.
- Не створюй дублікати реалізацій.
- Надавай повні файли під час зміни конфігурацій.
- Не змінюй незв'язані компоненти.

## 4. Тестування

- Визнач відповідні локальні тести.
- Запусти необхідні перевірки.
- Не приховуй помилки.
- Не змінюй тести лише для отримання PASS.
- Розділяй PASS, FAIL, SKIP та TIMEOUT.

## 5. Незалежний аудит

Після реалізації передай зміни Code Reviewer.

Для MikroTik Manager Bash додатково використовуй mikrotik-reviewer.

Врахуй знайдені підтверджені проблеми. Не виправляй непідтверджені зауваження автоматично.

## 6. Підсумок

Надай:

1. Що реалізовано.
2. Які файли змінено.
3. Які рішення прийнято.
4. Результати тестування.
5. Результати незалежного аудиту.
6. Відомі проблеми.
7. Що залишилося зробити.

Не створюй коміти та не виконуй push без прямого запиту.
