# Neovim — повна шпаргалка клавіатурних скорочень

## Позначення

- `<leader>` — **Пробіл** (`vim.g.mapleader = " "`); `<localleader>` — `\`.
- `N` — Normal, `I` — Insert, `V` — Visual, `X` — Visual selection; `Ctrl` — `<C-…>`, `Alt` — `<A-…>`, `Shift` — `<S-…>`.
- Клавіші **вікон Snacks** працюють усередині Picker/Explorer і можуть відрізнятися від загальних.
- Буферні LSP-призначення з'являються лише після `LspAttach`.

| Команда                    | Дія                                               |
| -------------------------- | ------------------------------------------------- |
| `:FormatDisable`           | Вимкнути автозапуск форматування глобально        |

| `:Mason`                   | Менеджер мовних серверів та утиліт                |

| `:verbose nmap <Space>/`   | Перевірити, що `Space /` виконує коментування     |
