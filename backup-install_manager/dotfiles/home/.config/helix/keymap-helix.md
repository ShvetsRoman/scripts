## 1. Позначення та режими

- `Space → y` — **послідовно** натиснути пробіл, а потім `y`.
- `Ctrl+w` — натиснути **разом** Control та `w`.
- `Alt+s` — натиснути **разом** Alt та `s`.
- `X` — велика літера, зазвичай `Shift+x`.
- `Esc` — повернутися до звичайного режиму.
- `LSP` — потрібен запущений language server; `TS` — потрібна граматика Tree-sitter.

| Режим           | Як увійти                    | Для чого                             |
| --------------- | ---------------------------- | ------------------------------------ |
| Normal          | `Esc`                        | Рух, виділення, команди              |
| Insert          | `i`, `a`, `I`, `A`, `o`, `O` | Введення тексту                      |
| Select / Extend | `v`                          | Рух **розширює** виділення           |
| Command         | `:`                          | Команди на зразок `:w`               |
| Space           | `Space`                      | Файли, LSP, clipboard                |
| Goto            | `g`                          | Перехід до позицій, визначень        |
| Match           | `m`                          | Парні дужки, лапки, текстові об'єкти |
| Window          | `Ctrl+w`                     | Розділення вікон                     |
| View            | `z`                          | Прокрутка та вирівнювання огляду     |

**Основна ідея Helix:** спочатку **виділення**, потім **дія**. Це відрізняється від багатьох команд Vim / Neovim.

## 4. Виділення рядків і текстових об'єктів

| Клавіші           | Дія                                                        |
| ----------------- | ---------------------------------------------------------- |
| `x`               | Виділити поточний рядок; повторно — розширити вниз         |
| `v` потім `k`     | Розширити виділення вгору                                  |
| `v` потім `j`     | Розширити виділення вниз                                   |
| `X`               | Розширити поточне виділення до повних меж рядків           |
| `Alt+x`           | Звузити виділення до меж рядків                            |
| `%`               | Виділити весь файл                                         |
| `miw`             | Виділити внутрішню частину слова                           |
| `maw`             | Виділити слово з оточенням                                 |
| `mip`             | Виділити внутрішню частину абзацу                          |
| `mif`             | Виділити внутрішню частину функції (TS)                    |
| `mm`              | Перейти до парної дужки (TS)                               |
| `ms"`             | Оточити виділення подвійними лапками                       |
| `md"`             | Прибрати навколишні подвійні лапки                         |
| `mr"'`            | Замінити навколишні подвійні лапки одинарними              |
| `Alt+o` / `Alt+i` | Розширити / звузити виділення по синтаксичному дереву (TS) |

**Як виділити 5 цілих рядків угору:** постав курсор у нижній рядок → `v` → `4k` → `X`. Під час руху вгору `k` розширює виділення, а `X` доводить його до повних рядків. **Стандартне `K` не рухає виділення вгору:** воно фільтрує мультивиділення за регулярним виразом.

## 5. Мультикурсори та масові зміни

| Клавіші | Дія                                                         |
| ------- | ----------------------------------------------------------- |
| `C`     | Додати курсор на наступному рядку                           |
| `Alt+C` | Додати курсор на попередньому рядку                         |
| `Alt+s` | Розбити виділення на окремі виділення по рядках             |
| `s`     | Виділити всі збіги регулярного виразу в поточних виділеннях |
| `S`     | Розбити виділення регулярним виразом                        |
| `,`     | Залишити лише головне виділення                             |
| `Alt+,` | Прибрати головне виділення                                  |
| `;`     | Згорнути виділення до курсора                               |
| `Alt+;` | Поміняти місцями якір і курсор виділення                    |
| `Alt+-` | Об'єднати виділення                                         |
| `K`     | Залишити тільки виділення, що збігаються з regex            |
| `Alt+K` | Прибрати виділення, що збігаються з regex                   |
| `&`     | Вирівняти виділення по колонках                             |

**Масова заміна `server` → `host`:**

1. `Esc` → `%` (увесь файл).
2. `s` → введи `\bserver\b` → `Enter` (окремі виділення всіх збігів).
3. `c` → введи `host` → `Esc`.

Виконуй ці дії тільки якщо справді потрібно замінити всі знайдені збіги, у тому числі в рядкових літералах і коментарях.

## 6. Буфер обміну

| Клавіші                   | Дія                                                    |
| ------------------------- | ------------------------------------------------------ |
| `Space → y`               | Копіювати виділення в **системний clipboard**          |
| `Space → Y`               | Копіювати головне виділення в clipboard                |
| `Space → p` / `Space → P` | Вставити із системного буфера після / перед виділенням |
| `Space → R`               | Замінити виділення вмістом clipboard                   |
| `y` / `p`                 | Внутрішній регістр Helix                               |
| `%` → `Space → y`         | Скопіювати **увесь файл** у системний буфер            |
| `x` → `Space → y`         | Скопіювати поточний рядок у системний буфер            |

Для Linux Wayland: `sudo pacman -S wl-clipboard`. Для X11: `sudo pacman -S xclip`. Якщо використовується SSH, системний буфер віддаленого комп'ютера не обов'язково збігається з локальним.

## 11. Git та зовнішні команди

Helix має picker змінених файлів і може відображати інформацію про Git, але **не замінює повноцінний Git-клієнт**. Надійний робочий процес — виконувати `git status`, `git diff`, `git add`, `git commit` у Kitty або іншому терміналі.

| Клавіші           | Дія                                                      |
| ----------------- | -------------------------------------------------------- | --------------------------------------------------------------- |
| `Space → g`       | Вибрати змінені файли (за наявності відповідної функції) |
| `]g` / `[g`       | Наступна / попередня зміна                               |
| `                 | ` → команда                                              | Пропустити виділення через shell-команду й замінити результатом |
| `Alt+             | ` → команда                                              | Передати виділення в команду, не вставляючи її вивід            |
| `!` → команда     | Вставити вивід команди перед виділенням                  |
| `Alt+!` → команда | Вставити вивід команди після виділення                   |
| `:sh git status`  | Виконати Git-команду через shell                         |

**Приклад:** виділи текст і натисни `|` → `sort` → `Enter`, щоб відсортувати виділені рядки (заміна вмісту результатом shell-команди). Обережно з командами, що змінюють дані.

## 13. Практичні приклади Bash, Rust, TOML

### А. Оточити слово лапками

```bash
packages=(git curl wget bat)
```

Наведи курсор на `git` → `miw` → `ms"`. Отримаєш `"git"`. Для **кількох** імен пакетів спершу сформуй окремі виділення, а потім застосуй surround до всіх.

### Б. Додати префікс до кількох рядків Bash

Початковий текст:

```bash
git
curl
wget
```

1. Виділи ці три рядки (`x` і розширення вниз).
2. `Alt+s` — по одному виділенню на рядок.
3. `I` → введи `# ` → `Esc`.

Результат:

```bash
# git
# curl
# wget
```

### В. Змінити назву Rust-символу в проєкті

У Rust-файлі постав курсор на назву функції, структури або змінної → `Space → r` → уведи нову назву → `Enter`. **Це LSP rename**, тому `rust-analyzer` повинен працювати; на відміну від текстової заміни він враховує семантику коду.

### Г. Відформатувати TOML

Відкрий `config.toml` → `:format` → `Enter`. Потрібен доступний formatter / LSP, здатний форматувати TOML; перевір `hx --health toml`.

### Ґ. Скопіювати весь конфіг до браузера

`Esc` → `%` → `Space → y`, далі у браузері `Ctrl+v`. Якщо не працює — перевір Wayland/X11 clipboard та `hx --health`.

### Д. Змінити всі входження слова

```rust
let timeout = 30;
println!("{timeout}");
```

`%` → `s` → `\btimeout\b` → `Enter` → `c` → новий текст → `Esc`.

Для ідентифікаторів у великому Rust-проєкті **краще `Space → r`**, щоб не пошкодити коментарі або інші, не пов'язані символи.

## 14. Власні клавіші у config.toml

Файл: `~/.config/helix/config.toml`.

Нижче **не повна заміна твого конфіга**, а окремий приклад, який можна об'єднати з ним:

```toml
# ============================================================
# HELIX — ПРИКЛАД ВЛАСНИХ КЛАВІШ
# ============================================================

[keys.normal]

# Копіювати головне виділення в системний clipboard.
# Перезаписує стандартну дію Y (якщо вона є у версії).
Y = "yank_main_selection_to_clipboard"

# Зберегти файл через Ctrl+S у Normal mode.
C-s = ":write"
```

**Не перепризначай `X = "extend_line_above"` без перевірки своєї версії:** стандартна `X` означає `extend_to_line_bounds`, а функція `extend_line_above` не є документованою стандартною командою у перевіреній офіційній таблиці. Для виділення вгору використовуй `v` → `k` → `X`.

Також звертай увагу на конфлікти з Kitty: деякі комбінації `Ctrl` / `Alt` можуть перехоплюватися терміналом.

## 15. Команди та перевірки

```bash
# Встановити Helix (Arch Linux)
sudo pacman -S helix

# Версія
hx --version

# Перевірка мов і зовнішніх залежностей
hx --health

# Практичний інтерактивний курс
hx --tutor

# Відкрити проєкт або файл
hx .
hx Cargo.toml
hx script.sh
```

У самому Helix:

| Команда              | Дія                                      |
| -------------------- | ---------------------------------------- |
| `:tutor`             | Інтерактивний курс                       |
| `:config-open`       | Відкрити основний конфіг                 |
| `:config-reload`     | Перезавантажити конфіг                   |
| `:theme`             | Подивитися / вибрати тему                |
| `:w` / `:wq` / `:q!` | Запис / запис і вихід / вихід без запису |
| `:lsp-restart`       | Перезапустити LSP                        |
