# Стабільна база v2.0.1 і план переходу до v2.0.2

## Підтверджений результат на Arch Linux

Користувач повідомив підсумок штатного `./tests/run-tests.sh` на Arch Linux: **95 PASS, 0 FAIL, 0 SKIP**, тривалість **91 с**, фінальний статус **УСПІХ**. Це стосується **v2.0.1 після Backups Menu Hints**, а не автоматично наступної v2.0.2.

## Межі v2.0.2

- Оновлено назву продукту в документації та збережено фактичне ім’я запускного файла `backup-install_manager.sh`.
- Неактивну копію пояснень Backup/Recovery вилучено з меню груп Dotfiles; загальне меню містить чинні пояснення.
- Archive створює архів `dotfiles/`, а не всього `HOME`. Архіватор відхиляє символьні й жорсткі посилання.
- Recovery використовує захисні копії, сформовані файловими операціями. Порожній список допустимий.
- Ротація `maintenance rotate TYPE KEEP` залишає налаштовану кількість копій (перевірте план і тип перед видаленням).
- Remote Sync не реалізовано. Файлові операції та зовнішні залежності незмінні.

## Перевірка після застосування

```bash
cd /шлях/до/backup-install_manager    # корінь проєкту, напр. ~/00_setup/scripts_bash/backup-install_manager
./backup-install_manager.sh --version    # звірка версії
./tests/run-tests.sh                     # повний регресійний набір
```

Позитивний прогін v2.0.1 є базою для порівняння; v2.0.2 потрібно перевірити окремо на Arch Linux, включно з ShellCheck.
