# Тестування та усунення проблем

## Основні перевірки

```bash
cd ~/Documents/backup-install_manager
bash -n backup-install_manager.sh
./backup-install_manager.sh --version
./backup-install_manager.sh doctor
./backup-install_manager.sh sources validate
./tests/run-tests.sh
```

Відомий повний успішний прогін поточної гілки на Arch Linux: 95 PASS, 0 FAIL, 0 SKIP; це історичний результат, не гарантія майбутніх запусків. Прямий запуск нового тесту потребує виконуваного біта; без нього застосовуйте `bash tests/ІМʼЯ.sh` або `chmod +x tests/ІМʼЯ.sh`.

## Типові питання

**Статус Dotfiles повторюється в Kitty.** `./backup-install_manager.sh dotfiles status > /tmp/setup-status.log 2>&1` та `grep -c 'status    HOME ↔ dotfiles' /tmp/setup-status.log` допоможуть відділити повторні запуски від scrollback. Один заголовок означає один вивід за запуск.

**ShellCheck FAIL.** Запустіть `./tests/run-tests.sh`, збережіть журнал. `SC1094` може бути наслідком синтаксичної помилки у підключеному файлі — спочатку виправляйте первинну помилку. Не вимикайте перевірку, щоб приховати проблему.

**Тест завершився без пояснення.** Запустіть `bash -x tests/НАЗВА.sh` для трасування й перевірте локальні `docs/`, `config/` і `.keep`.

**Заблокована операція.** Перевірте, чи немає іншої активної копії Backup Install Manager. Не видаляйте `.setup-manager.lock` без упевненості, що процес завершився.

**Помилка порівняння.** `dotfiles status` та `verify` повертають 0 за звичайних відмінностей, але 2 — за помилки читання/валідації.

**Немає Remote Sync.** Це запланований окремий модуль, який поки не починали; `remote up/down` в поточній версії відсутні.

## Меню «Резервні копії»: архіви й Recovery

- **Архіви** (`archive list`, `archive create`, `archive restore NAME`) зберігають і відновлюють **лише каталог `dotfiles/` проєкту**. Це не архів усього домашнього каталогу та не системний snapshot.
- Архіватор з міркувань безпеки відхиляє символьні й жорсткі посилання всередині `dotfiles/`. Якщо створення архіву завершується помилкою валідації, перевірте `find dotfiles -type l -print` і `find dotfiles -type f -links +1 -print`; не видаляйте файли без резервної копії.
- **Recovery** показує захисні знімки, створені файловими операціями програми. Якщо захисних копій ще не створювали, `recovery list` буде порожнім — це нормальна ситуація.
- Перегляд без змін: `./backup-install_manager.sh archive list`, `./backup-install_manager.sh recovery list`, `./backup-install_manager.sh recovery plan ID`.
- Перед відновленням архіву програма намагається створити захисний архів поточного `dotfiles/`; якщо цей крок не вдався, відновлення скасовується.
- Операції створення/відновлення архівів та видалення/відновлення Recovery з інтерактивного меню серіалізуються через `flock` для запобігання паралельному запису.
